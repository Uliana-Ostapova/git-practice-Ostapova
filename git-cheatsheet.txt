git init - создаёт новый локальный Git-репозиторий.

git status - показывает текущее состояние репозитория.

git add . - добавляет изменения в область подготовки.

git add названиеФайла - добавляет конкретный файл в область подготовки.

git commit -m "сообщение" - создаёт коммит с указанным сообщением.

git log -  показывает историю коммитов.

git branch - показывает существующие локальные ветки.

git switch -c feature - создаёт ветку feature и переключается на неё.

git switch main - переключение на ветку main.

git remote -v - показывает подключённые удалённые репозитории.

git remote add origin ссылка - подключает удалённый репозиторий.

git push -u origin feature - отправляет ветку feature на удалённый репозиторий.

git branch -a - показывает локальные и удалённые ветки.

Команды используемые в работе:
git remote add origin ссылка - подключение к GitFlic/GitHub.
git push -u origin feature - отправка ветки feature.
git branch - просмотр существующих веток.

Проблемы и их решения:
при подключении удалённого репозитория я использовала git branch -M main которая переименовала текущую ветку feature в main. После этого я создала feature заново командой git switch -c feature и удалила ветку master командой git branch -d master.
